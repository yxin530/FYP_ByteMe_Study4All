# Learning Profile Agent

## Responsibility

Analyze a student's learning activity and quiz outcomes to maintain a useful learning profile. It identifies performance patterns; it does not invent educational content.

## Inputs

- Quiz attempts, answers, scores, and difficulty
- Subject and topic identifiers
- Material references associated with the activity
- Existing profile and progress data

## Outputs

- Strengths and weak topics
- Topic-level progress and confidence indicators
- Trends and recommendations for the Orchestrator
- Evidence references to the underlying activity

## Constraints

- Do not diagnose a student or make unsupported claims.
- Do not use profile statistics as a substitute for source material when explaining a topic.
- Keep recommendations explainable through recorded activity.
